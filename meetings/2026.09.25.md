# 会议内容

## 1. 检索基类与三种检索方法的实现

- 完成了检索模块的整体架构设计，定义了统一的检索基类（Base Retriever），为后续不同检索策略的扩展提供标准化接口
- 基于该基类实现了三种具体的检索方法，确保各方法在输入输出格式、调用方式上保持一致，便于后续融合与对比实验
- 基类的抽象设计使得新增检索方法时只需继承并实现核心方法，降低耦合度，提升代码可维护性

## 2. HTML Parser 设计完成

- 完成了 HTML 文档解析器的设计与实现
- 能够从 HTML 页面中提取结构化文本内容，为后续 chunker 和检索模块提供干净的输入数据
- 解析结果与 PDF、DOCX 等其他格式的解析输出保持统一格式，便于下游模块统一处理

# 后续解决方案

- **关键词提取融合到 BM25 里面**
  - 将关键词提取能力与 BM25 算法结合，提升检索的相关性和准确度
  - 通过关键词权重增强 BM25 的匹配效果，使检索结果更贴合查询意图

  - 在检索前对用户提问进行分词和 token 化处理

- **在数据库里建立索引**
  - 针对 BM25 检索需求，在数据库中建立相应的倒排索引或全文索引
  - 提升检索效率，支持大规模文档的快速匹配
