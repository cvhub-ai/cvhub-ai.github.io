# 关键技术决策
1. **微服务容器化**
   - **粒度**：一个独立功能对应一个 Docker 容器（例如：OCR 功能独立为一个容器）。
   - **拆分要求**：AI Agent 模块需进一步拆分，将 **RAG 功能** 与 **LLM 功能** 分别部署在两个独立的容器中。
2. **服务间通信**：各容器间统一采用 **gRPC** 协议进行通信。
3. **目标检测技术栈**：`cvhub-objectdetection` 模块确定使用 **YOLO 模型** 进行推断，并采用 **ONNX Runtime** 进行部署。
