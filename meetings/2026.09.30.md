## 已确定的设计

### Database Schema
- 确定数据库 Schema 的整体设计。
- Chunk 数据需要同时支持 Keyword Retrieval 和 Vector Retrieval。

### Retriever Architecture

Retriever 基础架构：

**Base Retriever**
- Keyword Retriever
- Vector Retriever

**Keyword Pipeline**
1. 数据库构建时，从 Chunk 原始文本中提取 Tokens / Keywords。
2. 根据 Tokens 为 Chunks 构建倒排索引。
3. Query 输入后，同样提取 Query Tokens。
4. 通过倒排索引检索相关 Candidates。
5. 对 Candidates 使用 BM25 进行打分和排序。
6. 返回 Top-K 结果。

**Vector Pipeline**
1. 数据库构建时，通过 Embedding Model 对 Chunks 进行向量化。
2. 将 Embedding Vector 存入数据库。
3. Query 输入后生成 Query Vector。
4. 直接通过数据库进行 Vector Similarity Search。
5. 数据库完成相似度排序，返回 Top-K 结果。

### Retrieval Result
Keyword Retriever 和 Vector Retriever 分别返回 Top-K Candidates。

结果进入：

**Keyword + Vector → Fusion → Reranker → Final Results**
